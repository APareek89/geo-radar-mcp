# Hosting the remote MCP + "Connect & log in" from Claude

Goal: a public URL (`https://…/mcp`) a user pastes into Claude's custom connector, clicks **Connect**, logs in, and starts using the tools. Two pieces: **Render** (hosting) + **WorkOS AuthKit** (the login/OAuth authorization server). Our server is the OAuth *resource server* — it advertises WorkOS and verifies the tokens WorkOS issues.

```
Claude ──"Connect"──▶ our /.well-known/oauth-protected-resource ──▶ points to WorkOS AuthKit
Claude ──login/consent (DCR)──▶ WorkOS  ──issues JWT──▶ Claude
Claude ──POST /mcp  Authorization: Bearer <JWT>──▶ our server verifies JWT vs WorkOS JWKS ✅
```

## 1. WorkOS AuthKit (the login)
1. Create a free account at workos.com → create a project/environment.
2. **Dashboard → Authentication → AuthKit**: enable AuthKit and note your **AuthKit domain** (e.g. `https://your-app.authkit.app`). This is your `OAUTH_ISSUER`.
3. **Dashboard → Applications / Connect → Configuration**: enable **Dynamic Client Registration** (and "Client ID Metadata Document"). This is what lets Claude self-register.
4. **Register your MCP server URL as a Resource Indicator** = your Render URL (e.g. `https://geo-radar-mcp.onrender.com`). This becomes `OAUTH_AUDIENCE`.

WorkOS serves everything else (`/oauth2/authorize|token|jwks|register` + auth-server metadata) — we don't build any of it.

## 2. Render (the hosting)
1. Push this repo to GitHub (done — `APareek89/geo-radar-mcp`).
2. render.com → **New → Blueprint** → pick the repo. Render reads [`render.yaml`](../render.yaml) and provisions **web + worker + Postgres + Redis**.
3. Set the secret env vars Render marks as required (see table below). `MCP_API_KEY` is auto-generated; `DATABASE_URL`/`REDIS_URL` auto-wire from the provisioned services.
4. After first deploy, note the web URL (e.g. `https://geo-radar-mcp.onrender.com`) and set:
   - `OAUTH_ISSUER` = your AuthKit domain
   - `OAUTH_AUDIENCE` = that Render URL
   Then redeploy. Migrate the DB once: Render shell → `pnpm --filter @geo-radar/db db:migrate`.

## 3. Secrets to set in Render (dashboard → Environment)
| Key | Value | Notes |
|---|---|---|
| `ANTHROPIC_API_KEY` | your key | required (Haiku panel + parser) |
| `OAUTH_ISSUER` | `https://your-app.authkit.app` | WorkOS AuthKit domain |
| `OAUTH_AUDIENCE` | `https://<your-service>.onrender.com` | your public MCP URL |
| `GEMINI_API_KEY` / `GROQ_API_KEY` / `PERPLEXITY_API_KEY` | optional | extra panelists |
| `GA4_PROPERTY_ID` / `GA4_SERVICE_ACCOUNT_JSON` | optional | enables `attribute_ai_traffic` |
| *(auto)* `MCP_API_KEY` | generated by Render | back-channel bearer token |
| *(auto)* `DATABASE_URL`, `REDIS_URL` | wired from render.yaml | Postgres + Redis |
| *(preset)* `MCP_TRANSPORT=http`, `PORT=8080`, `PANEL_COST_CAP_USD_PER_RUN` | in render.yaml | — |

> Prefer your **GCP Cloud SQL** over Render Postgres? Delete the `databases:` block from `render.yaml` and set `DATABASE_URL` to your Cloud SQL connection string instead (keep Redis on Render, or use Upstash).

## 4. Add it to Claude
Claude Desktop → **Settings → Connectors → Add custom connector** → URL: `https://<your-service>.onrender.com/mcp` → **Connect** → the WorkOS login opens → sign in → done. The 8 tools appear.

## Verify auth locally (without WorkOS)
```bash
MCP_TRANSPORT=http PORT=8080 MCP_API_KEY=secret GEO_STORE=memory node apps/mcp-server/dist/index.js
curl -s localhost:8080/.well-known/oauth-protected-resource   # metadata
curl -s -o /dev/null -w '%{http_code}\n' -X POST localhost:8080/mcp -d '{}'   # 401
```
